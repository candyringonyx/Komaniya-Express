# \# Komaniya Express

# 

# Sistema de gerenciamento logístico desenvolvido em PHP, HTML, CSS, Bootstrap e MySQL.

# 

# \## Funcionalidades

# 

# \- Cadastro, edição, consulta e exclusão de produtos.

# \- Cadastro, edição, consulta e exclusão de endereços.

# \- Cadastro, edição, consulta e exclusão de transportadoras.

# \- Cadastro e consulta de fretes.

# \- Associação de produtos, endereços e transportadoras aos fretes.

# \- Consulta de fretes por data.

# \- Download de relatórios em CSV.

# 

# \## Tecnologias utilizadas

# 

# \- PHP

# \- HTML5

# \- CSS3

# \- Bootstrap 5

# \- MySQL

# \- XAMPP

# 

# \## Como executar

# 

# 1\. Instale o XAMPP.

# 2\. Coloque a pasta do projeto em `htdocs`.

# 3\. Inicie o Apache e o MySQL.

# 4\. Acesse o phpMyAdmin.

# 5\. Crie o banco de dados `komaniya-express`.

# 6\. Crie as tabelas necessárias.

# 7\. Acesse `http://localhost/komaniya-express/`.
